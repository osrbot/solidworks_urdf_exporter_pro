# OSURDF MuJoCo adapter

`validate_mjcf.py` is a development compatibility tool for independently checking
MJCF generated by `OSURDF.Core`. It is not the product export validator and is not
part of the end-user workflow.

The main SolidWorks export path uses pinned official MuJoCo tools bundled by the
installer. End users do not need Python, `pip`, or a separate MuJoCo installation.

Developers may run this script in an isolated environment where the official
`mujoco` Python package is already available:

```text
python validate_mjcf.py \
  --model <export>/MuJoCo/<robot>/robot.xml \
  --model <export>/MuJoCo/<robot>/scene.xml \
  --report <export>/MuJoCo/<robot>/official_compile_report.json
```

Exit code `0` means every model compiled with `mujoco.MjModel.from_xml_path`.
Exit code `1` means official compilation failed. Exit code `2` means the
official runtime was unavailable. XML generation alone is never reported as an
official compilation pass. This script only checks Python API loading; the product
validator performs the stricter compile/save/reload/zero-control-step sequence.
