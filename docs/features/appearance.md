# 外观页面

外观页只处理显示颜色，不参与 Collision 或 Inertial 计算。

![Link 外观页面](/screenshots/link-appearance.png)

## 页面字段

- **URDF 材质 ID**：由 RGBA 稳定生成，用于保持同色材质一致，通常不需要手工修改。
- **红、绿、蓝、Alpha**：每项范围为 0 到 1。
- **选色**：使用颜色选择器设置 RGBA。
- **自动配色**：按 Link 层级生成容易区分的颜色。

## 使用建议

- 需要保留设计颜色时，先检查插件读取到的 RGBA。
- 需要快速区分运动链时，使用自动配色。
- Alpha 为 1 表示不透明；调低前先确认目标 Viewer 支持透明材质。
- 导出后仍应在目标 Viewer 中检查颜色，因为不同渲染器的灯光和材质显示会有差异。
