# 可视与碰撞页面

这个页面同时设置 Visual 网格原点和 Collision 生成方式。Visual 用于显示，Collision 用于接触
计算，两者不必使用同样复杂的几何。

![可视与碰撞页面](/screenshots/link-collision.png)

## 页面字段

- Visual/Collision 原点位置和姿态。
- 碰撞策略。
- 碰撞预览。
- 网格粗细。
- STL 或 3DXML Visual 格式。
- STL 精简比例。

## 怎么选择碰撞策略

| 结构 | 建议起点 |
| --- | --- |
| 规则外壳、连杆 | 盒体或组件包围盒 |
| 轮子、轴、圆筒 | 圆柱原语 |
| 球形结构 | 球体原语 |
| 外形不规则但只需整体接触 | 凸包 |
| 需要更多轮廓 | 精简网格 |
| 必须保留细小接触特征 | 精确网格 |

先从简单策略开始。只有简单几何无法表达关键接触时，才增加网格复杂度。

## 预览与报告

点击预览检查碰撞体是否覆盖正确的 Link、是否遗漏重要区域、是否穿过相邻结构。导出器如果发生
策略回退，会在报告中同时记录用户选择和实际结果。
