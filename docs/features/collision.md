# 可视与碰撞页面

这个页面同时设置 Visual 网格原点和 Collision 生成方式。Visual 用于显示，Collision 用于接触
计算，两者不必使用同样复杂的几何。

![可视与碰撞页面](/screenshots/link-collision.png)

## 页面字段

- Visual/Collision 原点位置和姿态。
- 碰撞策略。
- 碰撞预览。
- 网格粗细。
- STL 或 3DXML Visual 格式。
- STL 精简比例 (%)。

## 精简比例

此设置是要移除的三角面比例，不是保留比例，也不是文件大小缩减承诺。
在页面调整此比例后，会统一应用到全部 Link 的可视 STL 和选择“精简网格”的碰撞 STL。
两者使用同一个目标减面比例；“使用可视网格”的碰撞直接复制已减面的可视网格，不重复减面。
“精确网格”不减面，长方体、圆柱、球体、组件包围盒和凸包仍按各自策略生成。

- 0%：不减面。
- 50%：目标移除一半三角面。
- 100%：尽可能精简；实际大小以导出结果为准。

比例旁会显示目标 STL 大小，例如精简 67% 时显示“约原始的 33%”。这不是磁盘压缩，也不改变模型尺寸。
没有当前网格的实测大小时，只显示百分比，不猜测 MB。导出结果会列出各 Link 减面前后的实际大小。

减面按相连区域分别处理，保留区域之间的接口；某个区域无法安全减面，不会连带放弃其他区域。
处理超时或候选网格未通过校验时，保留对应的原始几何并显示警告，不删除零件，也不改质量和惯性。

已有配置中保存的 `0.5` 现在表示目标移除 50% 的三角面；`0` 表示不减面，`1` 表示在形状
保护下最大限度简化。已有数值直接按此含义使用，无需转换。

形状保护可能使实际减面达不到目标。导出后检查轮廓、孔槽及关键接触特征，并查看导出报告中的
实际三角面数和实际减面统计；不要把目标百分比或导出前估算当作实际结果。

## 示例装配体实测

用户使用 `5656c5d77e18` 版本完成导出，精简比例为 70%，SolidWorks 网格粗细为粗糙。
ROS 1、ROS 2、OpenUSD 和 MuJoCo 四个目标全部成功，总耗时 8 分 38 秒。
以下比较使用本次导出记录的精简前 STL 大小，不与旧导出文件夹混比。MB 按 1,000,000 字节计算。

| 可视 STL | 精简前 | 导出后 | 大小减少 |
| --- | ---: | ---: | ---: |
| 大型 Link | 32.10 MB | 10.64 MB | 66.86% |
| 复杂小型 Link | 6.36 MB | 4.33 MB | 31.91% |
| 全部可视 STL | 41.35 MB | 16.20 MB | 60.82% |

总大小实际剩余约 39.18%，不是目标的 30%。十个 Link 中八个未达到 70% 的移除目标，
仅两个较小 Link 接近目标；这表示在形状保护下完成了部分精简，不等于导出失败。
精简不改变质量、质心或惯性，也不改变源装配体。

独立检查确认 ROS 网格引用和校验和有效，四个输出目标中的对应 STL 哈希一致。
MuJoCo 分别重新加载 `robot.xml` 和 `scene.xml` 并执行一次零控制步；OpenUSD 结构重开确认
17 个依赖层、16 个非空网格且无未解析依赖。没有运行 Isaac Sim，也没有验证长时间仿真或训练。
大型 Link 和复杂小型 Link 的固定视角对比未见明显几何缺失，但这不是严格的全表面误差或自相交证明。

### 本次验证发现的报告问题

- 四个轮子采用原生圆柱碰撞体，最终包不需要对应碰撞 STL；CSV 仍记录暂存 STL 大小和
  `collision_exists=true`，与最终包不一致。可读导出报告正确显示为 false，这不是轮子几何丢失。
- 顶层警告重复列出大型 Link 和复杂小型 Link 信息，未区分可视与碰撞且仍为英文。
  重复警告不表示多次几何失败；请结合各 Link 实际结果判断。

## 怎么选择碰撞策略

| 结构 | 建议起点 |
| --- | --- |
| 规则外壳、连杆 | 盒体或组件包围盒 |
| 轮子、轴、圆筒 | 圆柱原语 |
| 球形结构 | 球体原语 |
| 外形不规则但只需整体接触 | 凸包 |
| 需要更多轮廓 | 精简网格 |
| 必须保留细小接触特征 | 精确网格 |

先从简单策略开始。只有简单几何无法表达关键接触时，才增加网格复杂度。

## 预览与报告

点击预览检查碰撞体是否覆盖正确的 Link、是否遗漏重要区域、是否穿过相邻结构。导出器如果发生
策略回退，会在报告中同时记录用户选择和实际结果。
精简网格模式的实时预览仅显示原始 CAD 外形参考，不代表最终减面结果；请检查导出的碰撞网格。
