# 惯性页面

惯性页显示当前 Link 在所选坐标系中的质量、质心位置和惯性矩阵。

## 需要看什么

- **Link 坐标系**：惯性和质心最终表达在哪个坐标系中。
- **原点**：质心相对 Link 坐标系的位置和姿态。
- **质量**：单位为 kg，必须大于 0。
- **惯性矩阵**：单位为 kg·m²，包含 `ixx`、`iyy`、`izz`、`ixy`、`ixz`、`iyz`。

矩阵对称项会明确显示为 `iyx = ixy`、`izx = ixz`、`izy = iyz`，用于说明它们不是另一组独立
输入。

## 使用实测质量

优先在 SolidWorks 中设置材料、密度，或使用“覆盖质量属性”。插件读取所选组件的有效质量、
质心和惯性，而不只按几何重新估算。覆盖整个子装配体时，应把它完整分配给一个 Link；插件
不会猜测如何把整体覆盖值分配给多个 Link。

也可以直接在本页输入称量得到的质量。启用“按实测质量校准惯性”时，完整惯性矩阵按
`实测质量 / SW 原质量` 同比缩放。例如原质量 2 kg、实测 3 kg，矩阵各项乘以 1.5；质心、
主轴方向和等效长方体尺寸不变。

这个方法假设原模型的相对质量分布可信。若内部配重、材料分布或零件位置不对，应先修改
SolidWorks 模型，不能只靠改总质量解决。

手动输入惯性矩阵，或 SW 已明确覆盖惯性矩时，插件保留这些值，不自动缩放。可用
“恢复 SW 值”重新读取当前组件属性，撤销插件中的手动修改。预览和各导出目标使用同一组
最终数值；与原质量不同本身不再阻止导出，但非正质量和不满足物理条件的惯性仍会被拒绝。

旧配置没有记录数值来源时，先保留已有质量和矩阵，不擅自校准；需要使用 SW 分布时点击
“恢复 SW 值”，再输入实测质量。

## 显示等效惯性体

点击“显示惯性等效长方体”可以在 SolidWorks 中检查惯性体的位置和方向。它用于发现明显的坐标
或单位错误，不是要替代原始实体。

## 常见问题

- 质量为 0：检查零件材料、密度和被排除的组件。
- 质心跑到模型外很远：检查 Link 坐标系和组件变换。
- 惯性校验失败：检查单位、坐标方向以及质量属性是否来自正确配置。
- 预览失败但数值正常：先查看错误详情；预览显示与数值导出是两条不同检查路径。

不要用 Collision 几何代替质量属性。碰撞形状负责接触，惯性负责动力学。
