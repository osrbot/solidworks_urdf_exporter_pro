# 惯性页面

惯性页显示当前 Link 在所选坐标系中的质量、质心位置和惯性矩阵。

## 需要看什么

- **Link 坐标系**：惯性和质心最终表达在哪个坐标系中。
- **原点**：质心相对 Link 坐标系的位置和姿态。
- **质量**：单位为 kg，必须大于 0。
- **惯性矩阵**：单位为 kg·m²，包含 `ixx`、`iyy`、`izz`、`ixy`、`ixz`、`iyz`。

矩阵对称项会明确显示为 `iyx = ixy`、`izx = ixz`、`izy = iyz`，用于说明它们不是另一组独立
输入。

## 显示等效惯性体

点击“显示惯性等效长方体”可以在 SolidWorks 中检查惯性体的位置和方向。它用于发现明显的坐标
或单位错误，不是要替代原始实体。

## 常见问题

- 质量为 0：检查零件材料、密度和被排除的组件。
- 质心跑到模型外很远：检查 Link 坐标系和组件变换。
- 惯性校验失败：检查单位、坐标方向以及质量属性是否来自正确配置。
- 预览失败但数值正常：先查看错误详情；预览显示与数值导出是两条不同检查路径。

不要用 Collision 几何代替质量属性。碰撞形状负责接触，惯性负责动力学。
