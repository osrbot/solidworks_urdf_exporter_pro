# Link 树页面

Link 树决定机器人由哪些刚体组成，以及它们之间的父子关系。这里配置错误，后面的 Joint、惯性和
网格都会跟着错误。

## 页面可以做什么

- 新建、重命名和删除 Link。
- 拖动 Link 调整父子关系。
- 把 SolidWorks 组件分配到指定 Link。
- 复制或粘贴分支。
- 使用大纲方式批量整理层级。
- 保存配置，并在装配体重新打开后恢复。

## 配置顺序

1. 先建立唯一的根 Link。
2. 按真实刚体划分组件，不要按零件数量机械拆分。
3. 从根部向末端建立父子层级。
4. 确认同一个组件没有被多个 Link 重复使用。
5. 再进入 Joint 页面逐个设置连接关系。

## 常见错误

- 把会一起刚性运动的零件拆成多个 Link。
- 把跨越 Joint 的组件放进同一个 Link。
- 只看显示名称，没有确认实际装配分支。
- 修改装配体后直接沿用旧配置，没有重新检查组件归属。

完成后，树结构应当与机器人真实运动链一致。
