# Link 树页面

Link 树决定机器人由哪些刚体组成，以及它们之间的父子关系。这里配置错误，后面的 Joint、惯性和
网格都会跟着错误。

## 页面可以做什么

- 新建、重命名和删除 Link。
- 拖动 Link 调整父子关系。
- 把 SolidWorks 组件分配到指定 Link。
- 复制或粘贴分支。
- 使用大纲方式批量整理层级。
- 保存配置，并在装配体重新打开后恢复。

## 配置顺序

1. 先建立唯一的根 Link。
2. 按真实刚体划分组件，不要按零件数量机械拆分。
3. 从根部向末端建立父子层级。
4. 确认同一个组件没有被多个 Link 重复使用。
5. 再进入 Joint 页面逐个设置连接关系。

新增 Link 后可以继续整理结构，稍后再补全 Joint；正式导出前仍需填写必填项。编辑失败或取消，
不会留下只改了一半的树。

多选后应用不会清空各节点的 Joint 名称。要修改单个 Link 或 Joint 的属性，先只选中该节点。
Joint 重命名通过校验后，原有 Mimic 引用会同步更新；用户明确修改的引用、倍率和偏移会保留。

在大纲中重命名或移动现有 Link 时，保留行尾自动生成的标记。它用于保留该 Link 原有的参数和
组件绑定；新建 Link 可以直接增加标题行。

## 常见错误

- 把会一起刚性运动的零件拆成多个 Link。
- 把跨越 Joint 的组件放进同一个 Link。
- 只看显示名称，没有确认实际装配分支。
- 修改装配体后直接沿用旧配置，没有重新检查组件归属。

完成后，树结构应当与机器人真实运动链一致。
