# Joint 属性页面

Joint 页面分为“基本”“约束与安全”“Mimic”三个标签。每次只编辑左侧列表中选中的 Joint。

## 基本

需要确认：

- 父 Link 与子 Link；
- Joint 名称和类型；
- SolidWorks 参考坐标系；
- 运动轴；
- Joint 原点的位置与姿态。

坐标系和轴的下拉框各占一整行，长组件路径可以完整查看。坐标值来自 SolidWorks 参考几何；方向
不符合机械设计时，应回到模型中修改参考几何。

## 约束与安全

| 字段 | 什么时候填写 |
| --- | --- |
| 下限、上限 | `revolute` 和 `prismatic` 必填；`continuous` 不需要位置上下限 |
| 力矩或力 | 所有可动 Joint 都需要合理正数 |
| 速度 | 所有可动 Joint 都需要合理正数 |
| 摩擦、阻尼 | 有可靠参数时填写，未知时可以留空 |
| 校准、安全控制器 | 下游确实使用这些 URDF 字段时填写 |

插件会为缺失的必要正数提供最小默认值，但默认值只保证格式具有基本物理意义。真实机器人参数应
由用户修改，越界或非正数会立即提示。

## Mimic

只有一个 Joint 的运动明确跟随另一个 Joint 时才启用。选择被模仿的 Joint，并确认倍率和偏移。
普通串联关节不要启用 Mimic。

## 导出前检查

- 旋转和移动方向是否正确。
- 单位是否为弧度、米、牛顿或牛顿米。
- `continuous` 与有界 `revolute` 是否选对。
- 上下限是否符合真实机械范围。
