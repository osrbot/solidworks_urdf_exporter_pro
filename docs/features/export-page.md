# 模型与导出页面

最后一页用于填写功能包信息、选择输出格式并开始导出。这里的设置属于整台机器人，不属于单个
Link。

## 基本信息

- ROS 包名与版本。
- 功能包说明。
- 维护者名称和邮箱。
- 许可证。
- 作者或配置者。

只导出 OpenUSD 或 MJCF 时，也建议填写清楚名称和许可证，方便结果目录和报告被正确识别。

## 输出选项

- ROS 1 功能包。
- ROS 2 功能包。
- OpenUSD 机器人资产。
- MuJoCo MJCF 资产。

新建导出配置默认勾选四种输出；已有明确选择及仅导出 URDF 的旧路径保持原有选择。
至少选择一个，取消不需要的格式可减少导出时间。

## 仿真设置

公共仿真设置用于指定基座方式和单自由度 Joint 的被动、位置、速度或力控制意图。
OpenUSD 与 MuJoCo 使用独立标签页保存各自参数：USD 的刚度、阻尼、自碰撞和机器人类型，
以及 MJCF 的执行器增益和最大力。两套目标参数不会互相借用。

默认不创建执行器或主动驱动。未配置公共设置时保留旧配置；公共基座选择 `source` 时保留
目标原有基座行为，显式 `fixed` / `floating` 和公共 Joint 模式优先于目标旧设置。
这里只配置机器人资产，不生成训练世界、奖励函数、策略或训练工程。

MJCF 位置控制需要正刚度和明确填写的非负阻尼；速度控制需要正速度增益（阻尼列）。
未填完整时可以确认保存草稿，但设置页会标记缺失项。开始导出前会再次检查；默认返回修改，
也可明确选择跳过 MJCF，继续其他已选目标，不必等网格生成完才发现缺失。

## 两个导出按钮

- **导出 URDF（不含网格）**：适合只检查结构和数值，速度更快。
- **导出 URDF 和网格**：生成实际交付目录，OpenUSD 和 MJCF 需要这条路径。

导出时不要重复点击。完成后先看 `export_report.md`，再打开对应目标目录。

部分目标失败时，成功输出仍会保留，导出页面保持打开，可只勾选失败目标重试。旧输出本次未更新
或目录需要恢复时，以结果窗口和错误详情为准，详见[选择导出目标](/exports/)。
