# 模型与导出页面

最后一页用于填写功能包信息、选择输出格式并开始导出。这里的设置属于整台机器人，不属于单个
Link。

## 基本信息

- ROS 包名与版本。
- 功能包说明。
- 维护者名称和邮箱。
- 许可证。
- 作者或配置者。

只导出 OpenUSD 或 MJCF 时，也建议填写清楚名称和许可证，方便结果目录和报告被正确识别。

## 输出选项

- ROS 1 功能包。
- ROS 2 功能包。
- OpenUSD 机器人资产。
- MuJoCo MJCF 资产。

新建导出配置默认勾选四种输出；已有明确选择及仅导出 URDF 的旧路径保持原有选择。
至少选择一个，取消不需要的格式可减少导出时间。

## OpenUSD 设置

勾选 OpenUSD 后，底部会出现设置按钮，位置在“上一步”和导出按钮之间。只有需要指定固定/浮动
基座、自碰撞或 Joint 驱动意图时才打开；默认设置可以直接导出。

## 两个导出按钮

- **导出 URDF（不含网格）**：适合只检查结构和数值，速度更快。
- **导出 URDF 和网格**：生成实际交付目录，OpenUSD 和 MJCF 需要这条路径。

导出时不要重复点击。完成后先看 `export_report.md`，再打开对应目标目录。

部分目标失败时，成功输出仍会保留，导出页面保持打开，可只勾选失败目标重试。旧输出本次未更新
或目录需要恢复时，以结果窗口和错误详情为准，详见[选择导出目标](/exports/)。
