# UI 与导出设置修复记录

## 修复内容

1. **取消不再被无效配置困住。** 先询问是否保存，选择不保存即可退出；选择保存但校验或写入失败时，Joint 树和选中项会恢复，仍可继续修改。
2. **Mimic 引用严格区分大小写。** `joint_a` 和 `JOINT_A` 不再因为下拉框的匹配规则而被混淆。
3. **目标错误各自处理。** ROS 的邮箱、版本或控制配置有误时，只影响相关 ROS 目标，不再由页面提前阻止 OpenUSD 和 MuJoCo。未选择输出目标等共同错误仍会拦截。
4. **STL 设置以实际值为准。** 保存网格前回读单位、二进制格式、禁止正坐标平移和合并组件设置；退出时逐项恢复并回读。一个恢复失败不会妨碍其他项恢复。保留此前的坐标系有效值校验。
5. **首次 DPI 缩放只执行一次。** 页面先按设计尺寸构建，再统一缩放；输入行按正常控件高度计算，布局缓存不再保留被撑大的历史高度。OpenUSD 对话框补上 96 DPI 设计基准。
6. **结果窗口保留按钮空间。** 底部按钮栏设置最小高度，避免初次布局时偶发被压到 1 像素。导出进度窗口的样式保持不变。

## 远端布局验证

测试主机为 `192.168.31.108`，3840 × 2160、150% 缩放。
独立测试直接构建实际产品窗口，但不连接 CAD，也不修改装配体。

- 旧版 Joint 名称框高度为 81 像素；修复版为 42 像素。
- 基本页和约束页在默认窗口中完整显示，不需要纵向滚动条。
- 外观颜色区域由 1100 像素缩到 288 像素，RGBA 两行均可见。
- OpenUSD 客户区由未缩放的 900 × 560 恢复为 1350 × 840。
- 同时检查系统 DPI 与每显示器 DPI 启动方式；不把控件报告的 96 DPI 当作实际窗口 DPI。

## 验证范围

新增交互回归覆盖保存成功、取消保存、放弃修改、保存失败、异常恢复、Mimic 循环和大小写往返。
STL 专项覆盖设置返回值与有效值不一致、保存前设置变化、独立恢复与恢复失败汇总。
DPI 回归检查首次构造、设计尺寸只缩放一次、窗口缩放、页签切换和输入框边界。
