# 公共仿真设置

## 修改内容

- 模型导出页的“OpenUSD 设置”改为“仿真设置”。选择 OpenUSD 或 MJCF 时都可以打开。
- 公共区配置固定/自由基座，以及每个 Joint 的不生成驱动、位置、速度、力/力矩控制意图。
- OpenUSD 与 MuJoCo / MJCF 使用两个子标签，分别保存增益。切换标签不会把一边的增益复制到另一边。
- 原始配置没有公共设置时保留旧行为。“保持各目标原有行为”不会强制统一旧目标的基座设置。
- 仿真设置保存在根 Link 配置，随通常的 CAD 配置保存和恢复；不会写入零部件的质量属性。损坏设置不能悄悄用默认值继续导出仿真目标。
- MJCF 配置错误只影响 MJCF，OpenUSD 配置错误只影响 OpenUSD；公共意图错误影响消费它的两个仿真目标，不阻止正常 ROS 导出。

## 单位和驱动

公共数据使用 m、kg、s、rad。OpenUSD 沿用 SI 增益到角度制的转换。MJCF 本版只支持直接关节传动，明确写入 `gear="1"`，不开放复杂传动比配置。

- 位置控制：MJCF `position`，填写正刚度和非负阻尼。
- 速度控制：MJCF `velocity`，填写正速度反馈增益。
- 力/力矩控制：MJCF `motor`；OpenUSD 只记录下游运行时控制意图，不伪造等价 DriveAPI。
- MJCF 输出力上限优先使用该目标的显式配置，否则采用有效的 Joint effort 限值。缺少有效限值时拒绝该目标。
- fixed 和 Mimic 从动关节不生成独立主动驱动。没有公共驱动意图的 Joint 默认为不生成驱动，不等于锁死关节。

这不是完整训练环境：不生成地面、奖励、观测、重置、控制程序或自动调参。USD 加速度驱动、复杂执行器和传动参数不在本版新增范围内。

## 验证范围

- Core 138 项测试通过，包含配置 JSON、旧行为、目标参数校验、生成 XML，以及随包 MuJoCo 3.12.0 对生成模型的编译检查。
- 独立的自由基座测试模型验证了 position、velocity、motor 的正负响应和 +/-4.25 输出限幅。此模型由探针构建，不是用户小车的长时间仿真。
- 插件目标配置测试 26 项、配置序列化测试 13 项通过。
- 中英文文档构建通过；JSON Schema 语法检查通过。
- 布局回归的 89 项行为测试通过；新增 4 项中英文、96/144 DPI 预览测试通过，生成两个目标标签页的 8 张截图。
- 最终审查补充目标隔离回归：不能用公共模式覆盖掩盖非法 USD 参数；局部目标配置恢复失败不能影响其他有效目标。

安装包全量回归和远端实机验收结果在完成后补充。远端使用独立装配体副本，不修改原始装配体。
