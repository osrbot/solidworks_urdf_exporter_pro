# Link 编辑、界面适配与惯性校准修复 Brief

状态：代码修复和自动回归完成；真实 SW 覆盖属性、实际多显示器切换仍待复测。本轮未替换已安装插件。

## 修复了什么

### 1. Link 树编辑

- 把“编辑树”和“准备导出”的校验分开。新增 Link 时，可以先保留未配置完的 Joint，不再因为缺少 Joint 名称立即报错。
- 修改直接子 Link 数量、增删节点和拖拽，都先修改候选树。验证成功才更新界面；失败或取消后，界面和内部配置仍是原来那一棵树。
- 禁止拖动根节点、拖到自身或后代；删除 Mimic 引用目标前检查引用关系。
- 大纲保留节点身份。重命名不会变成删掉旧 Link、创建新 Link，从而丢失质量、参数或 CAD 绑定。无法判断的无标记重命名会拒绝，而不是猜。
- 草稿允许没填完，不代表可以直接导出；必填配置仍由导出阶段检查。

### 2. 界面适配

- 页脚按钮和输入框从逻辑尺寸按当前 DPI 计算，不再继承旧窗口放大后的宽高。
- DPI 变化时重建布局缓存；切页、缩放往返不会继续放大控件。
- 信息横幅重绘完整背景，清除窗口改变大小后留下的边框残影。
- 新增惯性操作放在现有惯性页，不增加新页面。已经确认满意的导出进度窗口保持不变。

### 3. 质量、惯性、预览和导出

- 读取 SW 所选组件的有效质量属性，包括质量、质心和惯性覆盖；按组件实例去重，避免父子组件重复计入。
- 整体装配体覆盖无法拆分给多个 Link 时明确拒绝，不用忽略覆盖值的几何结果冒充有效属性。
- 输入实测质量后，可按 `实测质量 / 原质量` 校准完整惯性矩阵。假设相对质量分布不变，质心、主轴和等效长方体尺寸保持不变。
- 手填矩阵及 SW 明确覆盖的惯性优先，不自动缩放。旧配置没有来源记录时保留旧值；点击“恢复 SW 值”后再选择质量校准。
- 校准始终从原始基准计算，不反复乘上一次的结果。质量输错后修正、COM 暂时留空时再改质量，也不会把过期显示值误判为手填惯性。
- 页面、方体预览和导出使用同一组最终参数。校准状态随配置保存，采用可选字段，不提升 schema 版本。
- 与 SW 原质量不同不再直接判错；质量为零、负数、非有限值或不满足物理条件的惯性仍阻止导出。关闭 SW 自动计算也不会关闭物理校验。

## 使用边界

只知道总质量，不能推断真实质量分布。校准适合 CAD 形状和相对分布可信、总质量需要按称量修正的情况；配重、材料或内部结构不对时，应先在 SW 中修正。
