# Link 实测质量校准验收

## 本次修改

代码提交：`23c267d`。只包含质量校准交互、对应测试和使用文档，不包含本地尚未完成的 CSV 与装配体准备流程修改。

- 输入整个 Link 的实测质量后，可以直接勾选“按实测质量校准惯性”，不必先重置。
- 旧配置、手动矩阵或 SW 覆盖惯性需要确认后才改用 SW 惯性作为校准基准。确认后保留输入的质量和质心；取消确认不替换原值。
- “恢复 SW 值”改名为“清除 Link 校准与手动修改”，明确它会清除插件内的质量、质心和惯性编辑。
- 校准结果只保存在 Link 配置，不修改 SW 零部件的材料、密度或覆盖质量属性。
- 预览与导出共用最终质量和惯性。同比校准保留质量分布，所以等效长方体尺寸不变，而质量和惯性矩阵一起变化。

## 人工复测步骤

使用装配体与依赖零件的独立副本，先记录原始文件哈希与 SW 有效质量属性。

1. 进入惯性页，选择包含多个组件的 `base_link`，记录质量、质心和惯性矩阵。
2. 输入新的正质量，直接启用校准。若弹出替换惯性确认，先取消，确认输入仍保留；再次启用并确认。
3. 检查质量是输入值，矩阵各项按 `实测质量 / SW 源质量` 缩放，质心不变。
4. 打开等效惯性长方体预览，再修改质量并移开输入焦点。检查预览刷新、没有报错，矩阵更新，方体尺寸保持一致。
5. 切换到另一个 Link 再返回，确认实测质量与校准模式没有丢失，也不影响其他 Link。
6. 保存测试副本配置后重新打开，确认校准仍可还原；导出时检查质量、惯性与界面一致。
7. 点击“清除 Link 校准与手动修改”，确认恢复到 SW 的有效属性，而不是改写 SW。
8. 复读 SW 属性并核对原始文件哈希，确认没有被插件修改。

空值、零值和负质量仍应拒绝，不能悄悄改用上一次有效值导出。仅修改总质量不能修正错误的内部配重或材料分布。
