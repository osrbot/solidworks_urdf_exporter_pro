后续已将 base_link 进一步减到约 10.81 MB，见 [接近三分之一体积的离线实验](2026-09-10-neo-one-third-experiment.md)。下文保留第一轮分区原型的结果。

## 解决什么问题

之前 base_link 和 imu_link 含少量退化面以及共享坐标形成的歧义邻接，整个 STL 会退回原件。
现在先划分可处理区域，各自调用已有减面器；不能处理的区域原样保留，最后重新组成一份完整 STL。
这些区域是三角面邻接分区，不代表已经识别出 SolidWorks 中的真实零件。

## 保留规则与核对

- 只有恰好两个方向相反的边记录才建立面邻接。
- 接触歧义边的整个分区保留；与退化面共享顶点的分区也保留，防止过滤退化面后误判邻接。
- 不超过 16 面的小分区、有逐面属性的分区、原始退化面均保留。
- 跨分区共享点及其关联三角面必须保持；候选不满足则只退回该分区。
- 每个原始 face ID 归属恰好一次；所有保留区域的完整 50 字节面记录保持一致。
- 重组保留原始 80 字节头，检查面数、文件长度、区段哈希、有限坐标及输出法线朝向；所有原文件 SHA-256 未变。
- 原始 7 个、8 个退化面没有被偷偷删除。未要求重组后的整个 CAD 三角面集合成为单一流形。
- 固定相机、相同比例的完整文件前后图未见明显缺件；这不替代全角度检查或严格几何证明。

新增 11 项离线契约测试覆盖邻接歧义、退化面邻居、点接触、接口变更拒绝、原始记录、零比例、全量保留、截断文件及非法比例。

## 复跑与边界

需要 NumPy、Pillow、Windows PowerShell，以及测试构建的 SW2URDF.dll 和同目录 geometry3Sharp.dll。

```powershell
python scripts/test_partition_stl.py
python scripts/prototype_partition_stl.py '<输入.stl>' '<全新输出目录>' --assembly '<测试构建>/SW2URDF.dll' --ratio 0.5
python scripts/assess_partition_stl.py '<输出目录>/report.json'
```

证据目录：`.codex-build/neo-partition-full`，含 base-half、imu-half、base-max、imu-max。
每份含源面归属、各分区输入/候选、重组 STL、报告、独立核对和前后图。

当前仍未证明严格 Hausdorff 距离、近重合接口、T 接点或全局无自交；采样误差保护不能替代这些证明。
