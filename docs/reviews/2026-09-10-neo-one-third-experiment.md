# NEO STL 接近三分之一体积的离线实验

日期：2026-09-10。目标是缩小实际二进制 STL，而不是压缩 ZIP、改文件格式或隐藏零件。
本轮仅创建工作区副本，没有改原始 NEO、安装插件、打包或修改正式导出入口。

## 结果

单位 MB 为 1,000,000 字节，不是 MiB。

| base_link 阶段 | 三角面数 | 文件字节 | 相对原始体积 |
| --- | ---: | ---: | ---: |
| 原始 NEO | 642,074 | 32,103,784 | 100% |
| 上一轮分区原型 | 510,926 | 25,546,384 | 79.6% |
| 更换局部 QEM 策略后 | 314,904 | 15,745,284 | 49.0% |
| 只固定异常区域的接口 | 281,044 | 14,052,284 | 43.8% |
| 0.5 mm 上限及更细比例搜索 | 217,358 | 10,867,984 | 33.9% |
| 最大四个区域进一步细搜 | 216,190 | 10,809,584 | 33.7% |

最终为 10.81 MB，减少约 66.3%。原体积严格除以三为 10.70 MB，尚差约 0.11 MB；未声称达到严格三分之一，更未达到 10 MB 硬上限。
额外测试端点折叠没有进一步减小文件。继续细搜最后仅减少约 58 KB，因此先停止追逐小差额，优先完成质量验证。

imu_link 同时完成一档保守实验：127,233 面、6,361,734 字节，降到 88,220 面、4,411,084 字节。它没有达到三分之一；本轮主要目标是 base_link。

## 实现变化

- 复用上一轮的原始面归属和分区，不把整个 CAD 三角面集合强行焊接成一个流形。
- 使用隔离安装的 PyMeshLab 2025.7.post1，比较带与不带平面约束的 QEM；不是复制 Blender 算法。
- 每个区域先平移、缩放到统一数值尺度，运算后转换回原坐标并写成 float32，再校验。
- 启用拓扑、边界和法向保护。关闭自动清理，不通过清除坏面或删除小零件取得减面量。
- 从“遇到歧义接触就保留整个区域”改为尝试固定接触三角面、只减内部选中面；事后仍要求接口三角面按坐标、方向及重数保持。
- 原件、此前已验证候选、新候选之间只接受更小且通过检查的结果。失败仍局部回退。
- 首轮把 qualitythr 设为 0 导致样本很早停滞；隔离对照发现恢复默认 0.3 后能继续减面。没有把这种停滞归咎于用户模型。

## 质量条件

新接受区域同时经过下列检查：

- 非空、面数下降、有限坐标、写出后无新退化面、无新重复面和非流形边。
- 分区连通性、边界分量、Euler 特征和一致的边方向不变。
- 原始跨分区共享点及其关联三角面保持。
- 每个源面、输出面各取顶点、边中点、重心，共七点，进行双向点到三角面距离检查。
- 距离上限取区域包围盒对角线的 0.5% 与绝对上限中的较小者。保守档绝对上限 0.2 mm，小体积档为 0.5 mm。单位依赖 NEO 的米制坐标，不能假定任意 STL 都是米。
- 闭合且体积非近零的区域，几何体积变化不超过 2%。没有据此重新计算质量或惯性。

源面归属、完整 50 字节原样保留区段、STL 头、最终计数和长度已核对。base 原始 7 个、imu 原始 8 个退化面仍保留；原件 SHA-256 未变。
baseline 链继承既有保护结果。单独的最终质量审计已重新检查包括继承区域在内的全部 287 个减面区域，全部通过，最大双向采样距离约 0.4999 mm，而不是仅信任本轮报告里的 max_error。
顶视、背面和整体对比未见明显缺件；但放大弹簧区域后，新版折面比原件明显。10.81 MB 是体积与外观的折中，不能宣称完全满足“看不出明显三角面”的外观要求。14.05 MB 档也保留供比较，未据此自动接入或替换插件。
这仍是采样误差，不是严格 Hausdorff 距离证明；没有证明全局无自交、近重合接口或 T 接点全部正确，也未完成碰撞仿真和训练验证。

## 测试与性能

本轮 Python 契约测试共 19 项通过：上一轮分区 11 项，MeshLab 实验 8 项。
新增覆盖已知距离、恒等距离、未找到表面的拒绝、米制缩放、冻结接口的实际减面路径、源顺序基线接续、收紧误差拒绝及端点模式。
修正了早期实验报告中的候选文件路径；完整 STL 的几何和哈希未因报告修正而改变。

最终 base-quarter 的热缓存读取、二进制校验和连续 float32 顶点/法线数组准备，交替 15 轮中位数约为 110.4 ms → 34.5 ms。
运行时存在其他本机负载，该数值是本次观察，不是完整 Robot Viewer 加载、GPU 上传或训练速度承诺。

额外减面也有代价：base-full 约 87 秒，base-protected 约 35 秒，base-fine 约 309 秒，最大四区域细搜约 110 秒；此前还有采样及原型步骤。
这些多次离线搜索不能原样放入交互式导出流程。正式接入前还需处理结果缓存、重复尝试、耗时预算、进度、取消、依赖和许可证评估。

## 文件与复查

全部证据在工作区 `.codex-build/neo-meshlab/`，原始用户网格未加入 Git。

- `base-protected/`：14.05 MB 保守版本。
- `base-quarter/`：10.81 MB 最小版本、分区报告及最终审计。
- `imu-protected-retry/`：4.41 MB 的 imu 版本。
- 每个目录的 `assessment.json` 记录独立字节核对和计时；`comparison.png` 是统一相机前后图。
- 最终 `quality-audit.json` 记录所有减面区域重新审计的结果；另有顶视、背面和局部比较图。

```powershell
# NumPy 和 Pillow 使用现有 Python 环境；MeshLab 只放在工作区。
python -m pip install --target .codex-build/mesh-lab-deps --no-deps pymeshlab==2025.7.post1
python scripts/test_partition_stl.py
python scripts/test_meshlab_experiment.py
python scripts/assess_partition_stl.py '<结果目录>/report.json'
python scripts/audit_partition_quality.py '<结果目录>/report.json' --max-error 0.0005 --views
```

实验入口为 `scripts/experiment_meshlab_partitions.py`。需要上一轮分区报告；使用 `--all-regions` 尝试接口保护下的其他区域，`--keep` 表示保留比例，**与插件现有“移除比例”不是同一个参数语义**。
各阶段的实际参数、基线路径及失败原因记录在 report.json 和 progress.jsonl，不能把一次链式搜索的结果归因于单个比例。
