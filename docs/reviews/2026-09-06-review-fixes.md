# 逻辑与性能审查修复简报

本轮修复上次审查确认的九项问题。不重新设计已经确认满意的进度窗口，不调整模型文件，不自动安装插件。

## 修复清单

| 问题 | 修复方式 |
| --- | --- |
| 修改 Link 坐标系后，手动质心或惯性仍沿用旧坐标系数值 | 属性页先记录待转换状态，预览/导出准备时统一转换手动值和基准源。重复保存不重复转换；旧坐标无法解析时保留草稿并报错，不猜测单位坐标系。 |
| Link 树多选后应用，把某个 Joint 名称清空 | 单节点属性的写回入口检查当前确实为单选；多选占位文本不参与写回。 |
| Joint 重命名后第一次保存成功，第二次保存因 Mimic 旧名称失败 | 校验通过后同步活动树中的 Mimic 引用；取消或失败的事务不修改原树，用户主动修改的引用、倍率和偏移保留。 |
| 惯性校验失败后，提示查看的 CSV 随临时目录被删除 | 清理前把诊断 CSV 复制到日志目录的 `failed-exports` 子目录，并在错误信息中给出位置。不复制大体积网格。 |
| 导出清空坐标系设置后没有恢复 | 分别保存和恢复全局导出坐标系及原文档旧版设置。逐项恢复，某项失败不阻断其余项；读回检查失败时明确提示。 |
| SolidWorks 拒绝或调整 STL 参数，报告却仍写请求值 | 检查设置返回值并读回实际参数；估算和报告使用读回值，发生调整时警告。无效参数在 STL 保存前停止，不影响 3DXML 的独立路径。 |
| 深层 Link 树校验反复扫描整棵树 | 单次建立节点索引，用迭代方式检测环，避免递归和重复祖先扫描，校验复杂度降为 O(n)。 |
| 未精简 STL 仍重复计算同一份三角面估算 | 精简比例为零时只估算一次，复用为基准值和当前值；不同精简设置仍分别估算。 |
| 切换 Link 清除两种预览时整幅 CAD 画面重绘两次 | 先清除惯性和碰撞预览，再统一重绘一次；没有预览时不重绘。独立关闭单种预览仍保持原行为。 |

现代坐标系设置的 API 作用域依据 [SolidWorks STL 导出选项文档](https://help.solidworks.com/2024/english/api/swconst/FileSaveAsSTLOptions.htm)：现代设置使用 `ISldWorks`，旧版文档设置单独处理。

## 验证记录

- 新增 80 个不连接真实 SolidWorks 实例的回归用例，首轮全部通过。覆盖草稿事务、惯性转换、序列化、错误诊断保留、设置回读恢复、树校验和预览清理。
- Test、Release 隔离构建通过；不执行 COM 注册，不覆盖当前安装目录。
- 原始 Mimic 探针：连续两次保存均通过，活动树与保存配置的引用一致。
- 原始多选探针：应用前后的 `b_joint` 保持不变。
- 同机 1,000 节点长链校验探针：修复前约 6,940 ms，本次约 2.66 ms。仅表示该校验函数的耗时，不代表整体导出加速倍数。
- 完整回归第二轮 **889/889 通过**，耗时约 209 秒。首轮既有结果弹窗按钮边界断言出现一次失败，单独重跑相关 12 项全部通过；保留断言并增加边界诊断信息，未证实该偶发失败根因。
- Core **82/82 通过**，包括固定版本 MuJoCo 3.12.0 的实际编译校验。首次运行遗漏运行时环境变量，6 项门禁失败；按仓库约定设置本机运行时路径和版本后完整重跑通过。

## 验证边界

本轮没有操作真实装配体或重新安装。COM Mock、算法测试及独立窗口测试不能代替真实 SolidWorks 对坐标系偏好、STL 参数读回和预览清理的验证；也不能据此声称已证明此前长时间 STL 保存问题的全部根因。
