# 验证范围

“导出成功”必须按实际执行的检查理解，不能扩大成目标工程已经可用。

| 层级 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 格式与单元测试 | 数据合同、转换规则和错误处理符合测试 | SolidWorks 或目标应用实际运行 |
| 平台构建 | 插件和工具可以在指定环境构建 | 用户装配体的几何与物理一定正确 |
| 有界运行时检查 | USD 可重开；MJCF 可由固定官方工具执行最小步骤 | Isaac、控制器、接触和任务效果 |
| 目标工程验收 | 指定模型在指定应用和任务中通过 | 其他机型、版本或参数自动通过 |

## 当前已覆盖

- SolidWorks 2023 上的实际插件 UI 和 `level_5` 装配手动测试。
- OpenUSD 使用固定 `usd-core 26.8` 生成、重开和结构检查。
- MuJoCo 使用固定 `3.12.0` 工具编译、保存、重载和一步零控制推进。
- ROS 2 最小夹具可通过手动触发门禁，在 Jazzy/Harmonic 或 Lyrical/Jetty 环境构建、启动并激活
  指定控制器。

## 用户仍需确认

- 自己装配体的 Link 分组、坐标系、轴、限位和惯性；
- 目标 Viewer 或仿真器中的材质、碰撞、接触和运动方向；
- 控制器参数、稳定性、性能和任务行为；
- 生产使用所需的版本、硬件与安全验收。

完整矩阵见[兼容性矩阵](/development/compatibility-matrix)。
