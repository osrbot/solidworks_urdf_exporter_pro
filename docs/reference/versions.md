# 版本怎么理解

项目中有几类版本，作用不同。小功能更新不应该随意修改数据格式版本。

## 插件版本

这是安装包和 DLL 的产品版本，用于识别安装的软件。修复 UI、文档或导出器实现时可以更新产品
版本，但不意味着配置格式必须升级。

## SolidWorks 配置 v2

`URDF Export Configuration (v2)` 是保存在 SolidWorks 装配体中的 PID 配置特征。只有持久化
结构发生不兼容变化时才需要新主版本。普通字段扩展应优先保持向后兼容。

## Robot schema v3

这是导出过程使用的临时规范文档版本，不是用户需要管理的文件夹。v3 用来表达各导出器共享的
机器人数据及 OpenUSD 仿真意图。新增可选字段且旧读取器仍能安全忽略时，不应仅为数字变化而
升级主版本。

## 外部运行时版本

OpenUSD `usd-core 26.8` 和 MuJoCo `3.12.0` 是当前自动化检查所使用的固定工具版本。它们用于让
验证可重复，不是要求用户安装相同版本的 Isaac Sim 或 MuJoCo 应用。

## 长期规则

- 产品版本按发布变化。
- schema 主版本只在不兼容合同变化时增加。
- 向后兼容的可选字段留在当前主版本。
- 迁移逻辑集中维护并有测试，不让 UI 暴露内部 schema 数字。
- 文档写清“哪个版本控制什么”，不把产品、配置和运行时版本混在一起。
