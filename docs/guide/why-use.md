# 为什么使用 SW2URDF

## 适合解决什么问题

当机器人结构已经在 SolidWorks 中完成，而后续工作需要 URDF、USD 或 MJCF 时，手工重复整理
Link 层级、坐标系、网格路径、质量和惯性既慢又容易出错。SW2URDF 把这些工作集中在一个三步
向导中，并在交付文件前做基本检查。

## 它替你完成什么

- 读取装配体中的组件、坐标系、参考轴和质量属性。
- 按用户配置建立 Link 和 Joint。
- 分别生成显示网格与碰撞几何。
- 输出 ROS 1、ROS 2、OpenUSD 或 MuJoCo 文件和检查报告。
- 各目标独立校验和替换输出；某个格式失败时保留其他成功结果，并在报告中区分未更新的旧输出与需要恢复的目录。

## 哪些事情仍需用户决定

- 什么组件属于同一个刚体。
- Joint 的真实类型、运动方向和位置限位。
- 执行器允许的力、力矩和速度。
- 碰撞几何需要保留哪些接触细节。
- 控制器、PID、摩擦、接触和任务参数。

插件可以减少机械录入和格式转换工作，但不能仅凭 CAD 外形推断控制与安全参数。

## 适合哪些人

- 需要从 SolidWorks 维护 ROS 机器人描述包的开发者。
- 需要把 CAD 机器人送入 Isaac Sim 或其他 USD 工具的开发者。
- 需要在 MuJoCo 中继续搭建控制与任务场景的开发者。
- 需要检查质量、惯性、碰撞和坐标方向的机器人团队。
