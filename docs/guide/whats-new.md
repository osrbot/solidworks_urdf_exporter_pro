# 相比社区原版有哪些变化

当前版本保留原社区版的 SolidWorks 导出流程，主要补齐复杂装配、物理检查、现代输出格式和使用
体验上的问题。

| 使用场景 | 原社区版 | 当前版本 |
| --- | --- | --- |
| 深层组件坐标系和轴 | 容易受名称、层级和当前配置影响 | 按实际组件实例定位，支持深层、同名和中文参考几何 |
| STEP 或固定装配 | 容易把约束状态当成 Joint 语义 | 以用户明确选择为准，Mate 识别只提供待确认建议 |
| 质量与惯性 | 主要读取并写出数值 | 增加单位、质心、张量和主惯量检查 |
| Collision | 选择较少，导出前不易判断 | 提供网格、原语、组件包围盒、凸包、精简和预览 |
| 外观 | 与网格设置混在一起 | 独立外观页，支持 RGBA、选色和自动配色 |
| 输出格式 | 主要是传统 URDF | 增加 ROS 2、OpenUSD 和 MuJoCo MJCF |
| 错误处理 | 常见错误不易定位 | 可复制错误详情、日志入口和导出报告 |
| 中文与布局 | 以旧英文界面为主 | 简体中文界面，长名称可完整查看，页面切换更流畅 |

## 页面上的直接变化

- Joint 的基本信息、参考几何、原点和轴分区显示，长路径不会挤成一小段。
- 约束页为缺失的必要正数提供最小默认值，用户修改后以合法的用户值为准。
- Link 页面分成惯性、可视/碰撞和外观三个标签。
- 已复测的窗口尺寸下，Joint 基本页和约束与安全页输入框边框完整，没有多余滚动条；不代表全部 DPI 和多显示器组合均已验证。
- OpenUSD 只有在用户需要时才打开设置，不占用主页面空间。

## 编辑 Link 时

- 增删 Link、调整直接子 Link 数量或拖拽改父级时，先校验修改；取消或校验失败不会留下部分树修改。
- 多选用于批量操作；修改单个 Link 或 Joint 的属性前先选中一个节点。多选后应用不会用占位文本清空 Joint 名称。
- Joint 重命名通过校验后，原有 Mimic 引用同步更新；用户明确修改的引用、倍率和偏移仍会保留。
- 修改 Link 坐标系后，手动质心和惯性在预览或导出准备时转换到新坐标系，重复保存不会重复转换。
  若原坐标系无法解析，会保留草稿并报错，应先解决引用问题再继续。
- 切换 Link 会清除惯性和碰撞预览，已输入的质量仍保留。首次预览准备的等待问题尚未解决，详见[快速开始](/guide/getting-started)。

## 新增输出

- **ROS 2 功能包**：用于现代 ROS 2 描述与后续控制配置。
- **OpenUSD**：输出可以整体搬运的机器人资产，供 Isaac Sim 或其他 USD 工具继续使用。
- **MuJoCo MJCF**：输出可载入的机器人模型，供用户继续添加场景、执行器和控制。
