# 快速开始

## 1. 准备装配体

- 使用已保存的装配体，第一次测试建议复制一份。
- 解析轻量化组件，确保参与导出的实体可访问。
- 为零件设置材料或密度，并在 SolidWorks 中检查质量与质心。
- 重建并保存。

## 2. 建立 Link 树

打开 `工具 > Export as URDF`。创建根 Link，再把组件分配到各个 Link。每个组件只应属于一个
Link，父子关系应与真实机构一致。

[查看 Link 树页面](/features/link-tree)

## 3. 配置 Joint

为每个非根 Link 确认父子 Link、Joint 名称、类型、参考坐标系和运动轴。可动关节还要确认力或
力矩上限、速度上限；有位置边界的关节还要填写上下限。

[查看 Joint 属性页面](/features/joint)

## 4. 检查惯性

确认质量、质心和惯性张量单位与方向正确。可以显示等效惯性体辅助检查，但最终以数值和导出报告
为准。

[查看惯性页面](/features/inertia)

## 5. 设置碰撞与外观

Visual 用于显示，Collision 用于接触。优先选择足够简单、同时保留关键接触形状的碰撞策略。
外观页可以设置 RGBA 或按 Link 层级自动配色。

[查看可视与碰撞](/features/collision) · [查看外观](/features/appearance)

## 6. 选择输出

至少选择一种：ROS 1、ROS 2、OpenUSD 或 MuJoCo MJCF。只勾选当前需要的格式，可以减少导出
时间和结果目录中的干扰。

[查看模型与导出页面](/features/export-page)

## 7. 检查报告

先查看输出根目录的 `export_report.md`，再查看对应输出目录中的报告和名称映射。错误信息会给出
出错位置和建议处理方式。

## 8. 在目标工具中确认

在实际 ROS、Isaac Sim、USD Viewer 或 MuJoCo 环境中检查外观、碰撞、惯性、轴方向和运动范围。
导出成功表示文件通过插件检查，不等于控制器和任务参数已经调好。
