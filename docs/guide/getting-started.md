# 快速开始

## 1. 准备装配体

- 使用已保存的装配体，第一次测试建议复制一份。
- 解析轻量化组件，确保参与导出的实体可访问。
- 为零件设置材料或密度，并在 SolidWorks 中检查质量与质心。
- 重建并保存。

## 2. 建立 Link 树

打开 `工具 > Export as URDF`。创建根 Link，再把组件分配到各个 Link。每个组件只应属于一个
Link，父子关系应与真实机构一致。

[查看 Link 树页面](/features/link-tree)

## 3. 配置 Joint

为每个非根 Link 确认父子 Link、Joint 名称、类型、参考坐标系和运动轴。可动关节还要确认力或
力矩上限、速度上限；有位置边界的关节还要填写上下限。

[查看 Joint 属性页面](/features/joint)

## 4. 检查惯性

确认质量、质心和惯性张量单位与方向正确。可以显示等效惯性体辅助检查，但最终以数值和导出报告
为准。

插件读取 SolidWorks 的有效质量属性，包括质量、质心和惯性覆盖值。整个子装配体的覆盖值不能
拆分给多个 Link；需要使用这类覆盖时，应把该子装配体完整分配给一个 Link。

输入实测质量（kg）并启用“按实测质量校准惯性”，可按 `实测质量 / SW 原质量` 同比缩放完整
惯性矩阵，保持质心、主轴方向和等效长方体尺寸不变。这要求原模型的相对质量分布可信。
手动输入的惯性矩阵或 SW 明确覆盖的惯性矩不会自动缩放。

旧配置未记录惯性来源时保留原值，不自动启用校准。需要重新以 SW 属性为基准时，点击
“恢复 SW 值”，再输入实测质量；这会撤销插件中的手动修改，但不会清除 SW 中的覆盖设置。
预览与各输出目标使用同一组最终数值，非正质量和不满足物理条件的惯性仍会阻止导出。

首次“预览并导出”的准备阶段及导出前惯性校验仍可能较慢，质量计算期间 SolidWorks 界面可能
暂时不响应。这一限制尚未解决，不能把窗口暂时无响应直接视为导出失败。

[查看惯性页面](/features/inertia)

## 5. 设置碰撞与外观

Visual 用于显示，Collision 用于接触。优先选择足够简单、同时保留关键接触形状的碰撞策略。
外观页可以设置 RGBA 或按 Link 层级自动配色。

[查看可视与碰撞](/features/collision) · [查看外观](/features/appearance)

## 6. 选择输出

新建导出配置默认勾选 ROS 1、ROS 2、OpenUSD 和 MuJoCo MJCF 四种输出。已有配置中的明确
选择及仅导出 URDF 的旧路径保持原有选择。至少保留一种；取消当前不需要的格式，可以减少
导出时间和结果目录中的干扰。

[查看模型与导出页面](/features/export-page)

## 7. 检查报告

先查看完成摘要。ROS 功能包的报告在 `config/export_report.md`，OpenUSD 和 MJCF 的报告在
各自目标目录的 `export_report.json`；再检查对应名称映射。错误信息会给出出错位置和建议处理方式。

多目标导出会逐项显示成功或失败。某个格式失败不会丢弃其他成功输出；失败目标若有旧输出，
会标注“旧输出本次未更新”，不要把旧文件当作本次成功结果。若提示需要恢复，请按错误详情
检查目录，不能假定旧输出完整。

部分失败后导出页面保持打开，可只勾选失败格式重试。装配体读取或公共模型校验失败仍会整体
停止；取消或严重错误也可能中断后续目标。惯性校验失败时，按错误信息中的路径查看保留的诊断 CSV。

## 8. 在目标工具中确认

在实际 ROS、Isaac Sim、USD Viewer 或 MuJoCo 环境中检查外观、碰撞、惯性、轴方向和运动范围。
导出成功表示文件通过插件检查，不等于控制器和任务参数已经调好。
