# 快速开始

这条路线只保留第一次导出真正需要做的事。更细的参数说明可以在完成首轮导出后再看。

## 1. 准备装配体

- 使用已保存的装配体，建议先复制一份用于测试。
- 解析轻量化组件，确保插件能访问参与导出的实体。
- 为零件设置材料或密度，并在 SolidWorks 中检查质量与质心。
- 重建并保存装配体。

## 2. 建立 Link 树

从 `工具 > Export as URDF` 打开插件。创建根 Link，再把组件分配到对应 Link。每个组件只应属于
一个 Link；拖动层级前先确认父子关系符合真实机构。

## 3. 配置 Joint

每个非根 Link 都需要一个 Joint。确认以下内容：

- 父 Link、子 Link 和 Joint 名称；
- Joint 类型；
- SolidWorks 参考坐标系和运动轴；
- `revolute`、`prismatic` 等关节的限位、力或力矩上限、速度上限；
- 确有机械耦合时再填写 Mimic。

插件会为必需但尚未填写的正数提供保守默认值。默认值只是让模型具备合法的最小物理含义，不能
替代真实设备参数；用户修改后的合法值优先。

## 4. 检查 Link

依次检查惯性、可视/碰撞和外观：

- 惯性：质量、质心和惯性张量单位是否正确；
- 可视/碰撞：Visual 是否完整，Collision 是否足够简单且保留接触形状；
- 外观：RGBA 是否符合预期，是否需要按 Link 层级自动配色。

## 5. 选择输出

至少勾选一个目标：ROS 1、ROS 2、OpenUSD 或 MuJoCo MJCF。第一次测试建议只选实际需要的
目标，减少等待时间和结果目录中的干扰。

## 6. 检查结果

先读输出根目录的 `export_report.md`。各目标目录还有自己的报告和名称映射。然后在实际目标环境
检查 Visual、Collision、Inertia、轴方向和 Joint 运动。

更完整的八步流程见 [Wiki Quick Start](/wiki/Quick-Start-zh-CN)。
