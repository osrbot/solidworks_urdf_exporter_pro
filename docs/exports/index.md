# 选择导出目标

只勾选当前要使用的格式。四种输出互相独立，可以一次选择一种或多种。

| 目标 | 适合场景 | 主要结果 |
| --- | --- | --- |
| ROS 1 | 维护已有 ROS 1 项目 | URDF、网格、配置和报告 |
| ROS 2 | ROS 2 描述、显示和后续控制 | URDF、网格、配置和报告 |
| OpenUSD | Isaac Sim 或其他 USD 工具 | `robot.usd`、几何文件、名称映射和报告 |
| MuJoCo MJCF | MuJoCo 场景与控制开发 | `robot.xml`、`scene.xml`、网格和报告 |

## 共同规则

- 至少选择一个目标。
- 未勾选的旧输出目录不会被这次导出覆盖。
- OpenUSD 和 MJCF 需要导出 STL 网格。
- 导出成功后仍要在目标工具中检查坐标、碰撞、惯性和运动方向。
