# Appearance

**English** | [简体中文](Appearance-zh-CN)

The Appearance page controls display color only. It does not change collision or inertia.

- Red, green, blue, and alpha values range from 0 to 1.
- Select Color opens the color picker.
- Automatic Coloring creates distinct colors by Link depth.
- The URDF material ID is generated from RGBA and normally needs no manual edit.

Review imported RGBA when preserving CAD colors, or use automatic coloring to distinguish the
kinematic chain. Check the final result in the target viewer because lighting and material rendering
vary between applications.
