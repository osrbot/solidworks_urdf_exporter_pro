# Link 树

**简体中文** | [English](Link-Tree)

Link 树决定机器人由哪些刚体组成，以及这些刚体之间的父子关系。这里配置错误，后面的 Joint、
惯性和网格都会跟着错误。

## 可以做什么

- 新建、重命名和删除 Link；
- 拖动 Link 调整父子关系；
- 把 SolidWorks 组件分配到指定 Link；
- 复制、粘贴或删除一个分支；
- 使用大纲方式批量整理层级；
- 保存配置，并在重新打开装配体后继续编辑。

## 建议顺序

1. 先建立唯一的根 Link。
2. 按真实刚体划分组件，不要按零件数量机械拆分。
3. 从根部向末端建立父子层级。
4. 确认同一个组件没有被多个 Link 重复使用。
5. 再进入 Joint 页面逐个设置连接关系。

## 深层组件和同名对象

当前版本会按实际装配分支识别组件、坐标系和轴。显示名称相同也可以区分，但用户仍应在界面中
确认选中的是正确分支。修改装配层级、替换组件或删除参考几何后，需要重新检查对应 Link 和
Joint。

## 保存与恢复

点击应用或保存后，配置随装配体保存。未保存的编辑可能在异常退出后提供恢复提示。恢复内容仍需
用户检查后再正式保存，不应在装配结构已经变化时直接接受。

## 常见错误

“直接子 Link 数量”只影响下一层。新 Link 可以先作为未完成的草稿保留，导出前再补齐 Joint 名称和
必需引用；修改失败时保留原树。多选不会把占位文字写入单个 Joint 名称，Joint 重命名通过检查后会
同步已有 Mimic 引用。

- 把会一起刚性运动的零件拆成多个 Link；
- 把跨越 Joint 的组件放进同一个 Link；
- 修改装配体后直接沿用旧组件归属；
- 只看名称，没有确认实际装配分支。

完成后，树结构应与机器人真实运动链一致。
